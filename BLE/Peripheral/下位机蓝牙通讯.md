# 蓝牙通讯协议文档

本文档描述了设备与上位机之间的蓝牙通讯协议。

## 1. 协议概述

- **服务 UUID**: `0xFFE0` (SimpleProfile)
- **指令通道**: `0xFFE1` (Characteristic 1) - 支持 Notify / Write
- **透传通道**: `0xFFE2` (Characteristic 2) - 支持 Notify / Write (用于大数据量透传或调试)
- **数据大小端**: 小端模式 (Little Endian)，低字节在前

## 2. 帧结构

所有指令和响应均遵循以下帧结构：

| 字节偏移 | 长度 (Byte) | 字段 | 说明 |
| :--- | :--- | :--- | :--- |
| 0 | 1 | **LEN** | 总长度 (包含 LEN 本身, CMD, Payload, CRC) |
| 1 | 1 | **CMD** | 指令类型 |
| 2 ~ N | N-3 | **Payload** | 数据负载 (可选) |
| N-1 | 1 | **CRC** | 校验和 |

**CRC 算法**:
```c
uint8_t CalcCrc(uint8_t *buf, uint16_t len_without_crc) {
    uint8_t crc = 0;
    for (int i = 0; i < len_without_crc; i++) {
        crc += buf[i];
    }
    return crc + 0xEC;
}
```

## 3. 指令定义 (Command)

| CMD | 值 | 方向 | 说明 | Payload 格式 |
| :--- | :--- | :--- | :--- | :--- |
| **WRITE** | 0x01 | 上位机->设备 | 写属性 | `[PID][Value] [PID][Value]...` |
| **READ** | 0x02 | 上位机->设备 | 读属性 | `[PID] [PID]...` |
| **NOTIFY** | 0x03 | 设备->上位机 | 属性通知/应答 | `[PID][Value] [PID][Value]...` |
| **ACK** | 0x04 | 设备->上位机 | 操作成功应答 | 无 (或包含补充信息) |
| **ERROR** | 0x05 | 设备->上位机 | 错误应答 | `[Error String]` |
| **ACTION** | 0x06 | 上位机->设备 | 执行动作 | `[ActionID] [Params...]` |

## 4. 属性定义 (PID)

用于 `WRITE` / `READ` / `NOTIFY` 指令中标识数据类型。

| PID | 值 | 数据类型 | 说明 |
| :--- | :--- | :--- | :--- |
| **SWITCH** | 0x01 | uint8 | 开关状态 (0:关, 1:开) |
| **MODE** | 0x02 | uint8 | 运行模式 (0:自动, 1:制冷, 2:除湿, 3:送风, 4:制热) |
| **TEMP_SET** | 0x03 | uint16 | 设定温度 (放大10倍传输, 如 26.5℃ 传 265) |
| **TEMP_ROOM** | 0x04 | int16 | 环境温度 (放大10倍传输) |
| **FAN_SPEED** | 0x05 | uint8 | 风速 (0:自动, 1:低, 2:中, 3:高) |
| **LOCK** | 0x06 | uint8 | 锁定状态 |
| **ERROR** | 0x07 | uint16 | 故障码 (按位定义) |
| **LORA_CFG** | 0x10 | Struct | Lora配置: `NodeID(2) + Channel(1)` |
| **IR_CFG** | 0x11 | Struct | 红外配置: `Brand(1) + Type(2)` |
| **DEV_INFO** | 0x12 | Struct | 设备信息: `RunTime(2) + Power(2)` |
| **TIMESTAMP** | 0x13 | uint32 | 系统时间戳 |
| **SYS_PARAMS** | 0x14 | Struct | 系统运行参数查询 (见 4.2) |
| **SYS_CTRL** | 0x15 | Struct | 系统参数控制 (见 4.3) |
| **ALL_STATE** | 0xF0 | Struct | **全状态查询** (聚合核心状态，仅用于 READ/NOTIFY) |

### 4.1 ALL_STATE 返回数据结构 (9 Bytes)
当读取 `PID_ALL_STATE` 时，返回的数据顺序如下：
1. `SWITCH` (1 Byte)
2. `MODE` (1 Byte)
3. `TEMP_SET` (2 Bytes)
4. `TEMP_ROOM` (2 Bytes)
5. `FAN_SPEED` (1 Byte)
6. `ERROR` (2 Bytes)

### 4.2 SYS_PARAMS 返回数据结构 (16 Bytes)
当读取 `PID_SYS_PARAMS` 时，返回的数据顺序如下：
1. `nodeId` (2 Bytes)
2. `channel` (1 Byte)
3. `loraStatus` (1 Byte)
4. `scanCycle` (1 Byte)
5. `irType` (2 Bytes)
6. `mode` (1 Byte, 0:本地 1:远程)
7. `errorCode` (2 Bytes)
8. `tempRoom` (2 Bytes, 放大10倍)
9. `runTime` (2 Bytes, 分钟)
10. `loadPower` (2 Bytes, W*10)

### 4.3 SYS_CTRL 写入数据结构 (6 Bytes)
当写入 `PID_SYS_CTRL` 时，数据顺序如下：
1. `nodeId` (2 Bytes)
2. `channel` (1 Byte)
3. `irType` (2 Bytes)
4. `mode` (1 Byte, 0:本地 1:远程)

## 5. 动作定义 (ActionID)

用于 `ACTION` 指令 (CMD=0x06)。

| ActionID | 值 | 参数 | 说明 |
| :--- | :--- | :--- | :--- |
| **RESET** | 0x01 | 无 | 设备复位 |
| **IR_MATCH** | 0x02 | `[IR Data...]` | 红外匹配指令发送 |
| **IR_LEARN** | 0x03 | `[IR Data...]` | 红外学习指令发送 |
| **IR_SEND** | 0x04 | `[IR Data...]` | 红外透传发送 |
| **SAVE_PARAMS**| 0x05 | 无 | 保存当前参数到 Flash |

## 6. 通讯示例

### 6.1 查询设备所有状态
**发送 (Read All)**:
- Hex: `04 02 F0 C8`
- 解析: Len=4, Cmd=READ(0x02), PID=ALL_STATE(0xF0), CRC=Calculated

**接收 (Notify All)**:
- Hex: `0E 03 F0 01 01 09 01 14 01 02 00 00 E9`
- 解析:
    - Len: 14 (0x0E)
    - Cmd: NOTIFY (0x03)
    - PID: ALL_STATE (0xF0)
    - Data:
        - Switch: 01 (开)
        - Mode: 01 (制冷)
        - TempSet: 09 01 -> 0x0109 = 265 (26.5℃)
        - TempRoom: 14 01 -> 0x0114 = 276 (27.6℃)
        - Fan: 02 (中速)
        - Error: 00 00 (无故障)
    - CRC: 0xE9

### 6.2 设置温度为 26.0℃ 并 开启设备
**发送 (Write Multi)**:
- Hex: `08 01 01 01 03 04 01 35`
- 解析:
    - Cmd: WRITE (0x01)
    - PID1: SWITCH (0x01), Val: 01 (On)
    - PID2: TEMP_SET (0x03), Val: 04 01 (260 = 26.0℃)
    - CRC: 0x35

**接收 (Ack)**:
- Hex: `03 04 F3`
- 解析: ACK (0x04), CRC

### 6.3 发送红外透传数据
**发送 (Action IR)**:
- Hex: `08 06 04 AA BB CC DD EE 52`
- 解析:
    - Cmd: ACTION (0x06)
    - ActID: IR_SEND (0x04)
    - IR Data: AA BB CC DD EE
    - CRC: 0x52

**接收 (Ack)**:
- Hex: `03 04 F3`

### 6.4 查询系统运行参数
**发送 (Read SYS_PARAMS)**:
- Hex: `04 02 14 XX`
- 解析: Len=4, Cmd=READ(0x02), PID=SYS_PARAMS(0x14), CRC=XX

**接收 (Notify SYS_PARAMS)**:
- Hex: `15 03 14 01 00 05 04 3C 00 01 00 00 10 00 2C 01 2C 01 XX`
- 解析:
    - nodeId: 0x0001
    - channel: 0x05
    - loraStatus: 0x04
    - scanCycle: 0x3C
    - irType: 0x0001
    - mode: 0x00
    - errorCode: 0x0010
    - tempRoom: 0x012C (30.0℃)
    - runTime: 0x012C (300min)
    - loadPower: 0x012C

### 6.5 设置系统运行参数
**发送 (Write SYS_CTRL)**:
- Hex: `09 01 15 01 00 05 01 00 01 XX`
- 解析:
    - Cmd: WRITE (0x01)
    - PID: SYS_CTRL (0x15)
    - nodeId: 0x0001
    - channel: 0x05
    - irType: 0x0001
    - mode: 0x01
